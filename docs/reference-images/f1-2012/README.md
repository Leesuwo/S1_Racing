# F1 2012 개발용 레퍼런스 이미지

이 폴더는 `S1 2012 Open-Wheel` 차량의 외관을 개발·검토하기 위한 로컬 레퍼런스 패키지다. 이미지는 게임 런타임, production 번들, 차량 텍스처로 import하지 않는다.

## 사용 규칙

- [F1 2012 Google 이미지 검색](https://www.google.com/search?udm=2&q=f1+2012)는 다양한 사진을 찾기 위한 시각적 탐색 인덱스로 유지한다. Google 검색 결과 자체를 원본·라이선스 증명으로 사용하지 않는다.
- 아래 파일은 Wikimedia Commons의 개별 `File:` 설명 페이지에서 출처·작성자·라이선스를 확인한 뒤 저장했다.
- 실제 팀 로고·스폰서·드라이버명·고유 리버리를 `LowPolyCar`에 복제하지 않는다. 사진에서 노즈·사이드포드·서스펜션·배기·리어 에어로의 공통 형상만 추출한다.
- 사진은 투시와 렌즈 왜곡이 있는 실차 관찰 자료다. 치수 도면으로 사용하지 않고 상대 비율과 부품 관계를 확인하는 기준으로 사용한다.
- 1280px 파일은 Commons가 제공하는 축소본이며, 크롭·색상 보정·리터칭은 하지 않았다.

## 온보드·콕핏뷰 영상 기준

저작권이 있는 공식 영상은 저장소에 복사하지 않고 원본 페이지 링크만 기록한다.

- [Formula1.com — Brazil 2012: Best Onboards](https://www.formula1.com/en/video/brazil-2012-best-onboards.1687508295906982814): 2012년 레이스 온보드 시점, 제동·turn-in·전방 시야 변화 확인
- [Formula1.com — Sebastian Vettel 2012 United States GP pole lap](https://www.formula1.com/en/video/mega-quali-laps-sebastian-vettels-pole-lap-at-the-2012-united-states-grand-prix.1714053993819089057): 고속 코너에서의 조향 입력과 전방 시야 고정 확인
- [Top Gear — Mercedes W03 onboard camera with Nico Rosberg](https://www.topgear.com/car-news/motorsport/new-mercedes-f1-car): 2012 W03의 실제 운전자 시야·무릎 간격·복잡한 휠 조작 참고
- [F1 TV — 2012 season archive](https://f1tv.formula1.com/page/926/full-race-replays-and-highlights): 시즌 전체 레이스·온보드 탐색용 공식 색인

영상에서 S1에 반영할 관찰값은 헬멧이 화면 중앙을 가리지 않는 낮은 착좌점, 전륜과 프런트 윙이 시야 하단에 일부 노출되는 카메라 높이, 스티어링 휠이 화면 하단 중앙을 차지하는 구도, 조향 시 손·휠·노즈가 함께 움직이는 관계다. 실제 팀 리버리·로고·드라이버 자산은 복제하지 않는다.
