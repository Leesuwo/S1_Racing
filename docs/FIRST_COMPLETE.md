# S1 Racing — 1차 완성 기준

## 정의

1차 완성은 오프라인 단일 트랙 프로토타입이 한 번의 레이스 주말 흐름을 처음부터 결과까지 결정적으로 실행하고, 플레이어와 AI가 동일한 차량 물리 경계를 통과하며, 타이어·레이스크래프트·트랙 규칙·최소 운영 상태를 관찰 가능한 스냅샷으로 제공하는 상태다.

## 포함 범위

- 120Hz fixed-step 차량 물리와 Rapier 4륜 접지
- 입력 프리셋·테스트 트랙·AI 교육·단일 AI·다차량 그리드
- 퀄리파잉 Q1→Q2→Q3, Race Weekend 단계와 최소 전략
- 트랙 리밋·랩 무효화·패널티·차량 접촉 응답
- 타이어 온도·마모·공기압·컴파운드 교체
- 추종·추월·방어·충돌 회피 racecraft 상태 머신
- 접촉 손상·성능 저하·플래그·최소 피트 서비스
- 결정성 digest, 단위 테스트, 브라우저 E2E, 아키텍처·빌드 검증
- 차량이 트랙 밖으로 이탈하거나 정지한 경우의 퇴역·레이스 시간 상한을 통한 결과 수렴

## 1차 완성에서 제외

온라인 멀티플레이, 실제 차량 데이터 재현, 실제 피트 레인 차선·속도 제한, Rapier 다차량 차체 형상 충돌의 완전한 통합, 전체 대회 규정, 생산용 그래픽·사운드는 다음 제품 단계의 범위다.

## 완료 게이트

```bash
npm run verify
```

통과 기준은 타입 검사, 전체 단위 테스트, 아키텍처 검증, 프로덕션 빌드, 사용자에게 보이는 주말·타이어·레이스크래프트·운영 E2E다. 실행 환경 때문에 브라우저 서버를 열 수 없는 경우에는 완료로 표시하지 않고 동일 명령을 권한 있는 환경에서 재실행한다.

## 다음 단일 마일스톤

1차 완성 이후에는 M4로 실제 피트 레인·다차량 Rapier 차체 충돌·규정 확장 중 하나만 선택해 진행한다. 우선순위는 주행감과 결정적 물리를 보존하는 다차량 물리 통합이다.
