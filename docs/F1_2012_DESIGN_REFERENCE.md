# F1 2012 차량 디자인 참조 패키지

## 1. 목적과 사용 범위

이 문서는 S1 Racing의 오픈휠 차량을 **2012년형 Formula One 차량의 기술적 분위기와 형태 언어를 참고해 독창적으로 설계하기 위한 조사 원본**이다.

- 실제 팀·차량·드라이버·스폰서 리버리를 게임 자산으로 복제하지 않는다.
- 아래 사진은 형상 관찰용 참조이며, 런타임에 외부 사진을 텍스처로 넣지 않는다.
- 실제 차량의 성능값을 추정하거나 현재 물리값으로 확정하지 않는다. 물리 수치는 기존 `initial_assumption`/`simulation_required` 정책을 따른다.
- 이미지 파일을 저장소에 추가할 때는 해당 파일의 설명 페이지에서 라이선스와 저작자를 확인한 뒤 `docs/ASSET_LICENSE_REGISTER.md`에 파일 단위로 기록한다.

조사 기준일: 2026-07-29

## 2. 먼저 고정할 2012년형 공통 문법

### 2.1 실루엣

2012년 규정은 전방 차체의 최대 높이를 낮췄지만, 공기 흐름을 위해 모노코크 상부는 높게 유지하려는 설계가 가능했다. 그 결과 대부분의 차량에 눈에 띄는 단차형 노즈가 나타났다. McLaren MP4-27, Marussia MR01, HRT F112처럼 낮고 매끄러운 노즈를 선택한 차도 있어, 하나의 형상을 그대로 복제하기보다 두 설계 철학을 비교해야 한다.

권장 관찰 순서:

1. 정면: 노즈 끝의 높이, 단차의 폭, 프런트 윙 지지대 간격
2. 측면: 노즈에서 모노코크로 올라가는 경사, 전륜 앞 오버행, 사이드포드의 언더컷
3. 위: 콕핏·에어박스·사이드포드·엔진 커버가 만드는 중앙 능선과 후방 수축
4. 후면: 리어 윙, 빔 윙, 배기 출구, 리어 서스펜션과 디퓨저의 시각적 층

### 2.2 규정에서 직접 확인되는 시각 기준

아래 값은 차량을 정확히 재현하기 위한 목표 치수가 아니라, 2012년형 형상을 이해하기 위한 **규정 경계**다.

| 항목 | 2012 규정에서 확인되는 기준 | 디자인 해석 |
|---|---:|---|
| 전체 폭 | 타이어 제외 최대 1,800 mm | 노출 휠과 차체의 폭 대비를 유지한다. |
| 전체 높이 | 최대 950 mm | 에어박스·롤 구조·리어 윙이 만드는 높이 계층을 보존한다. |

| 전진 기어 | 최대 7단 | 시각 참조용 파워트레인 설명은 7단으로 통일한다. |
| 배기 출구 | 후방 방향, 차체 중심선에서 떨어진 제한 구역 | 디퓨저 바로 옆의 낮은 배기가 아니라 높은 후방 배기를 관찰한다. |

### 2.3 공력·기계 패키지

- 배기 블로운 디퓨저가 제한되면서 팀들은 배기 출구를 후방 상부로 옮기고, 사이드포드 상면·엔진 커버·리어 서스펜션 주변으로 흐름을 다시 관리했다.
- 프런트 윙은 단순한 한 장의 날개가 아니라 메인 플레인, 플랩, 엔드플레이트, 노즈 지지대, 턴잉 베인의 묶음으로 읽어야 한다.
- 2012년에는 후방 pull-rod 서스펜션이 광범위하게 사용되어, 리어 휠에서 기어박스 쪽으로 올라가는 가느다란 링크가 시각적 특징이 되었다.
- 오픈 콕핏, 노출된 4개 휠, 높은 에어박스/롤 구조, 얇은 프런트 윙과 높은 리어 윙이 기본 인상을 만든다.
- V8·KERS·7단 시퀀셜 변속기는 시대 배경을 설명하는 기술 자료다. S1의 물리 구현에 실제 엔진 수치를 이식하지 않는다.

근거: [RaceFans 2012 규정 기술 프리뷰](https://www.racefans.net/2012/01/27/2012-technical-preview/), [FIA 2012 규정 변경 승인 내용](https://www.f1technical.net/news/16957)

### 3.1 전체 노즈 비교 자료

가장 먼저 확인할 자료는 [2012년 전체 차량 프런트 엔드 비교](https://gurpzf1.wordpress.com/2012/04/09/front-end-comparison/)다. 12개 차종의 노즈 높이·폭·스텝 형상·프런트 윙과의 관계를 한 화면에서 비교할 수 있다. 해당 글은 다음을 구분해 설명한다.

- 다수 차량: 높은 모노코크와 낮은 노즈 끝을 동시에 유지하는 스텝 노즈
- McLaren·Marussia·HRT: 낮은 노즈를 선택해 무게중심과 공력 개발의 균형을 다르게 잡은 계열
- Ferrari: 짧은 노즈가 프런트 윙 뒤쪽에 놓이는 별도 해법
- McLaren 초기형: 노즈 아래 `snow plough` 턴잉 베인. 실제 게임에는 해당 부품을 그대로 복제하지 않고, 저폴리 공기 흐름 가이드로 재해석한다.

[McLaren MP4-27과 Ferrari F2012 정면·측면 비교](https://www.ausmotive.com/2012/02/04/mclaren-mp4-27-v-ferrari-f2012.html)도 두 설계 철학의 차이를 확인하는 데 유용하다. 이 비교 이미지는 정확한 치수 도면이 아니라 상대 형상 참고 자료로만 사용한다.

## 4. 색상과 리버리 관찰 규칙

2012년 그리드의 색상은 차종을 빠르게 구분하게 만들었지만, 실제 게임 구현에서는 그 색 배치와 로고를 복제하지 않는다.

관찰할 것은 브랜드가 아니라 다음의 **배치 원리**다.

- 차체 중앙의 주색과 사이드포드·엔진 커버의 보조색 비율
- 노즈 끝, 프런트 윙, 리어 윙에 어두운 색을 배치해 시각적 무게를 만드는 방식
- 전륜 뒤에서 사이드포드 아래로 이어지는 색상 스트라이프
- 상부에서 후방으로 흐르는 한 줄의 그래픽과 작은 번호판 영역
- 광택 도장, 무광 카본, 금속성 부품, 타이어의 거친 표면 대비

S1용 안전한 해석은 다음과 같다.

| 실제 참조에서 관찰 | S1에서 사용할 표현 |
|---|---|
| 팀 고유의 주색 | 새로운 주색 1개와 중성색 1개를 조합 |
| 스폰서 띠와 로고 반복 | 로고 없는 2~3개의 비대칭 그래픽 면 |
| 드라이버 번호 | 게임 내 차량 식별용 자체 번호 체계 |
| 실제 팀 심벌 | 추상화한 기하학 엠블럼 또는 무표식 |
| 실제 카본 패턴 | 단순한 어두운 flat-shaded 재질 |

## 5. S1 차량을 설계하기 위한 권장 기준선

### 5.1 권장 기준 차량

특정 팀을 복제하는 대신, 다음의 혼합 기준으로 `S1 2012 Open-Wheel`을 설계한다.

- 노즈: RB8·F2012 계열의 높은 모노코크 + 분명한 스텝을 참고한다.
- 프런트 윙: Ferrari·Force India의 넓은 지지대와 다층 플랩을 단순화한다.
- 콕핏: 2012년형 오픈 콕핏과 높은 롤 구조를 유지한다. Halo는 넣지 않는다.
- 사이드포드: Force India·Toro Rosso처럼 앞쪽이 깊게 파인 언더컷을 사용하되, 면 수를 제한한다.
- 엔진 커버: Red Bull·Mercedes처럼 콕핏 뒤에서 에어박스로 올라갔다가 후방으로 좁아지는 단일 능선을 만든다.
- 배기: 2012년형 고후방 배기의 위치감만 참고하고 실제 공력 이득을 시뮬레이션했다고 표현하지 않는다.
- 후방: Lotus·McLaren 계열의 좁은 코크 보틀과 높은 리어 윙, 빔 윙, 단순화한 디퓨저를 층으로 배치한다.
- 서스펜션: 전방 push-rod, 후방 pull-rod의 대비를 시각적으로 보인다.

이 조합은 2012년의 공통 문법을 읽을 수 있으면서도 어느 한 팀의 차체·리버리·브랜딩을 그대로 재현하지 않는다.

### 5.3 디자인 완료 판정

- 저폴리 모델의 모든 크기·재질·색상은 공통 설정으로 조정할 수 있다.

## 8. 98% 유사도 목표의 구현 기준

사용자가 요청한 “F1 2012 차 디자인 98% 유사도”는 특정 팀 차량 한 대의 복제가 아니라, **2012년형 오픈휠 차량으로 인식되는 외관 요소를 98% 가까이 보존하는 시각 목표**로 정의한다. 실제 차종이 지정되지 않은 상태에서는 사진과의 객관적 픽셀 유사도를 보장할 수 없으므로, 다음의 검증 가능한 형상 항목을 목표로 삼는다.

| 외관 항목 | 구현 기준 | 현재 상태 |
| --- | --- | --- |
| 비율 | 물리 기준의 휠베이스 3.30 m·트랙 폭 1.60 m에 시각 휠 축을 정렬 | 반영 |
| 노즈 | 낮은 팁, 높은 모노코크, 분명한 2012년형 스텝 | 반영 |
| 프런트 윙 | 메인 플레인·플랩·엔드플레이트·노즈 지지대 | 반영 |
| 콕핏 | 헤일로 없는 오픈 콕핏·시트·스티어링 휠·헬멧 볼륨 | 반영 |
| 사이드포드 | 흡입구·깊은 언더컷·코크 보틀 수축 | 반영 |
| 엔진 커버 | 중앙 능선·에어박스·롤 구조 | 반영 |
| 배기 | 후방 상부 배기 위치감과 열 배출구 | 반영 |
| 후방 공력 | 리어 윙·DRS 플랩·빔 윙·중앙 지지대·디퓨저 스트레이크 | 반영 |
| 기계 요소 | 전방 push-rod·후방 pull-rod·브레이크 덕트·노출 휠 | 반영 |
| 브랜드 경계 | 팀 로고·스폰서·드라이버·실제 리버리 배열 배제 | 유지 |

이 기준은 `src/world/LowPolyCar.tsx`의 `S1_2012_OPEN_WHEEL_DIMENSIONS`와 station 기반 차체 geometry로 구현했다. 렌더러는 물리 상태를 읽기만 하며, 형상 보정 때문에 휠 힘·질량·입력·AI 제어를 변경하지 않는다. 특정 차종을 98% 수준으로 맞추려면 다음 단계에서 해당 차종과 정면·측면·후면 기준 이미지를 별도 승인해야 한다.
