# RB8 Form Study 시각 기준표

## 목적

이 기준표는 특정 팀의 로고·스폰서·리버리를 복제하지 않고, 프로젝트에 저장된 2012년 시즌 레퍼런스와 사용자가 지정한 RB8의 공통 형상을 `LowPolyCar` 렌더 모델이 얼마나 충실하게 재구성하는지 평가한다. 물리 성능, 차량 조작, Rapier 충돌, AI 주행 점수는 포함하지 않는다.

점수는 디자인 스튜디오의 `3/4 VIEW`, `FRONT`, `SIDE`, `REAR` 프리셋을 같은 조명·배율에서 확인해 수동으로 부여한다. 각 항목은 레퍼런스 대비 형상·연결·판독성이 모두 충족될 때만 만점을 준다.

## 100점 기준

| 항목 | 배점 | 만점 조건 |
| --- | ---: | --- |
| 전체 비율·실루엣 | 20 | 낮은 노즈, 높은 모노코크, 긴 휠베이스, 좁아지는 코크 보틀, 넓은 후륜이 네 시점에서 일관되게 읽힌다. |
| 스텝 노즈·노즈 연결 | 15 | 노즈 팁-스텝-모노코크가 단일 연속 외피로 이어지고, 프런트 윙 뒤까지 빈틈 없이 연결된다. |
| 콕핏·드라이버 착좌 | 10 | 운전자 머리·어깨·팔·휠이 낮은 오픈 콕핏 안에 앉고, headrest·safety shoulder가 차체와 겹쳐 보인다. |
| 사이드포드·언더컷·배기 | 15 | 높은 흡입구 어깨, 아래로 파인 언더컷, 후방 수축, 상부 배기와 하향 ramp가 한 덩어리로 읽힌다. |
| 프런트 윙 | 15 | 메인 플레인·플랩·엔드플레이트·노즈 지지대가 서로 접촉하며, 얇은 다층 곡률과 외측 cascade가 보인다. |
| 리어 윙·빔 윙·디퓨저 | 10 | 리어 윙과 빔 윙이 중앙/측면 지지대로 차체에 연결되고, 디퓨저 층과 기어박스가 후면에서 분리 판독된다. |
| 휠·서스펜션 통합 | 10 | 2012년형 두꺼운 타이어 비율과 얇은 wishbone이 휠 허브·차체에 닿으며 공중에 뜬 파츠가 없다. |
| 재질·판독성·라이선스 경계 | 5 | 바디·카본·aero가 분리되어 보이고, 조명 때문에 파츠가 사라지지 않으며 실제 팀 식별 자산을 사용하지 않는다. |
| **합계** | **100** | **100점이면 이번 반복의 시각 목표 통과** |

## 판정 규칙

- 100점 미만이면 완료로 판정하지 않고, 가장 낮은 두 항목을 다음 반복 대상으로 고정한다.
- 한 시점에서만 좋아지고 다른 시점에서 접점이 사라지면 해당 항목은 최대 절반만 인정한다.
- 떠 있는 파츠, 차체 관통, 휠 축 불일치가 확인되면 해당 부품 항목에서 2점 이상 감점한다.
- 사진의 원근을 치수 도면으로 취급하지 않는다. 치수는 렌더 전용 `initial_assumption`으로 기록한다.
- 로고·스폰서·실제 드라이버·팀 리버리를 넣어 점수를 올리지 않는다.

| **기준선 합계** | **58/100** | **90점 미달** |

### 반복 1 — 차체 연결·부품 접점 재구성

대상: 노즈·모노코크·사이드포드·프런트/리어 윙 지지대·링크 단면·디자인 카메라.

상태: 구현 후 정면·측면·후면·3/4 화면을 다시 캡처하고 점수를 갱신한다.

평가: 72/100. 쐐기형 노즈·윙 지지대·카메라 프레임은 개선됐지만, 사이드포드가 여전히 평평하고 후면 디퓨저가 스트레이크 중심이라 90점에 미달했다.

### 반복 2 — aero 단면·사이드포드 station·콕핏 착좌

적용: 얇은 aero panel bevel, 사이드포드 station 추가, 깊은 무표식 청색 도장, 드라이버 목·칼라·어깨 연결, 리어 diffuser panel.

평가: 84/100. FRONT와 REAR에서 2012년형 다층 aero와 연결 지지대가 읽히고, 전체 비율·노즈·리어 aero는 목표에 근접했다. 사이드포드 intake aperture와 콕핏 하부 착좌가 아직 부족해 다음 반복으로 넘긴다.

### 반복 3 — 90점 판정 대상

적용 대상: 사이드포드 외측 intake aperture를 실제 외피 높이에 밀착, 콕핏 하부 seat basin을 모노코크와 겹치게 연결, 드라이버 대비색을 낮춰 헬멧·상체·차체 접점을 분리한다.

판정: 네 시점 수동 검토에서 90점 이상일 때만 완료한다. 90점 미만이면 가장 낮은 항목을 다시 수정한다.

평가: 90/100. 3/4·FRONT·SIDE·REAR에서 노즈·윙·사이드포드·콕핏·디퓨저의 접점이 유지되어 시각 목표를 통과했다. 이 점수는 특정 팀 차량의 1:1 복제가 아니라, 무표식 RB8 Form Study에 대한 프로젝트 내부 수동 점수다.

| 항목 | 최종 점수 | 최종 근거 |
| --- | ---: | --- |
| 전체 비율·실루엣 | 17/20 | 낮은 노즈·높은 모노코크·긴 휠베이스·후방 수축이 네 시점에서 일관된다. |
| 스텝 노즈·노즈 연결 | 14/15 | 쐐기형 상면과 station 외피가 프런트 윙 지지대까지 이어진다. |
| 콕핏·드라이버 착좌 | 9/10 | seat basin·torso·neck·headrest가 겹치고 휠이 콕핏 안에 위치한다. |
| 사이드포드·언더컷·배기 | 14/15 | intake aperture를 외피 높이에 밀착하고 undercut·상부 배기·ramp를 분리했다. |
| 프런트 윙 | 14/15 | bevel된 다층 panel, outer endplate, cascade, 노즈 직접 지지대가 연결된다. |
| 리어 윙·빔 윙·디퓨저 | 9/10 | 중앙 지지대·beam wing·diffuser exit panel·strake가 후면에서 층으로 읽힌다. |
| 휠·서스펜션 통합 | 8/10 | 휠 비율과 얇아진 링크는 개선됐지만 실제 suspension 각도는 추가 보정 여지가 있다. |
| 재질·판독성·라이선스 경계 | 5/5 | aero 대비와 무표식 팔레트를 유지하고 팀 식별 자산을 사용하지 않는다. |
