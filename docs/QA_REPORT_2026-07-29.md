# S1 Racing QA Report — 2026-07-29

## 결론

차량 외관·휠 렌더링·물리 스냅샷 변경은 집중 검증을 통과했다. 네 바퀴 회전 상태가 `VehicleRenderSnapshot`을 통해 전달되고, Driving·Training·Race Weekend가 같은 `LowPolyCar` 계약을 사용한다.

WebGL 컨텍스트 cleanup을 E2E 종료 경계에 추가한 뒤, 전체 `npm run verify`를 최종 완료 기준으로 통과했다.

## 변경 범위

- 4개 바퀴의 누적 `wheelSpinRad` 렌더 상태 추가
- Rapier 네 바퀴 각속도 우선 동기화
- 순수 AI 경로의 속도·휠 반지름 fallback 회전
- 앞바퀴 조향축과 구름축 분리
- 콕핏 림·미러·프런트 윙 스트레이크·리어 윙 엔드플레이트 보강
- 기존 팀·드라이버·스폰서 자산 미사용
- 연속 R3F E2E 뒤 WebGL 컨텍스트를 해제해 브라우저 테스트 누적을 방지

## 남은 위험

- Rapier 초기화 deprecated parameters 경고가 기존 상태로 남아 있다.
- 연속 E2E에서는 각 테스트 종료 때 `WEBGL_lose_context`로 Canvas를 해제한다. 이 cleanup이 제거되면 Chromium의 컨텍스트 누적으로 Training·Race Weekend requestAnimationFrame이 멈출 수 있다.
- 실제 2012 팀별 타이어·공력 데이터가 없으므로 물리 수치는 `initial_assumption`이다.
- `wheelSpinRad`는 시각 회전 상태이며 pitch·roll·차고 기반 동역학을 대체하지 않는다.
