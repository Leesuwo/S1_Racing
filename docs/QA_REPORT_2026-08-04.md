# PS2 리팩토링 통합 QA 보고서 — 2026-08-04

## 결론

`codex/ps2-refactor`의 PS2 nostalgia 시각 계획 P0~P6을 구현·검증했다. 그래픽 변경은 렌더 전용 경계를 유지했으며, 물리·AI·입력 회귀 없이 실제 로컬 웹 화면에서 검수했다.

## 범위

- 트랙 색·높이·경계 가독성
- 차량 저폴리 실루엣·무광 재질·50% 축소 판독성
- 추적·콕핏 카메라, 속도 FOV, 연석·벽 접촉 feedback
- 불투명 HUD·메뉴·핵심 계기판 계층
- `nostalgia-soft`, `nostalgia-sharp`, `clean-debug` Canvas 프로필
- 960×540·1440×900 최종 화면 캡처

## 시각 검증

- P1: 도로·잔디·연석·벽의 색과 높이 계층을 렌더 전용으로 분리했다.
- P2: 차체 면을 `flatShading`과 낮은 금속성·높은 거칠기로 통일했다. 480×270 축소 캡처에서 플레이어·AI 방향과 색을 확인했다.
- P3: 속도 FOV kick은 최대 3°로 제한했고, 접촉 impulse는 상승 이벤트·지수 감쇠로 제한했다. 가속 후 추적·콕핏 캡처를 확인했다.
- P4: HUD 핵심 계기판과 진단 영역을 분리하고 Canvas 위 blur를 제거했다. 960px에서도 차량과 다음 경계가 유지됐다.
- P5: 세 화면 프로필을 동일 Training 장면에서 비교했다. HUD·입력·물리는 프로필 전환의 영향을 받지 않았다.
- P6: [최종 캡처 매트릭스](PS2_VISUAL_BASELINE_2026-08-04.md)의 네 화면·두 viewport를 갱신했다.

## 남은 위험과 보류

- Rapier 초기화의 deprecated parameters 경고는 기존 코드 경고이며 이번 시각 변경의 실패가 아니다.
- Production build의 500KB 초과 chunk 경고는 기존 Rapier·앱 번들 구조의 위험으로 남아 있다. P5에서 새 후처리 패키지는 추가하지 않았다.
- `nostalgia-soft`는 가벼운 CSS filter만 사용한다. 강한 CRT scanline·색수차·내부 저해상도 target은 판독성과 성능 근거가 확보될 때 별도 검토한다.
- 오디오 믹서·사운드 자산 계약이 현재 M2A-0 범위에 없으므로 RPM·슬립·연석 오디오 연결은 보류했다.
